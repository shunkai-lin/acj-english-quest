# ACJ 皙潔英文闖關 — 設計與決策紀錄

日期：2026-08-24　對象：林皙潔（6 歲）

## 一、定位與架構決策

| 項目 | 決定 |
|---|---|
| 站別 | **獨立新站**，不掛在加分網站底下 |
| Firebase | 共用既有專案 `classroom-gacha-rewards`，但用**獨立集合 `acjenglish`**（比照喵喵版 `kitty` 的做法），與 `classes` / `kitty` 互不干擾 |
| 技術 | 純前端單檔 `index.html` + `questions.js` + `pokemon-data.js`，無建置流程 |
| 發音 | 瀏覽器內建 **Web Speech API**（`speechSynthesis`, `en-US`, rate 0.85），不需任何音檔 |
| 獎勵 | 沿用既有扭蛋規則：**滿 10 分可扭，扭一次扣 10 分**，抽第一世代 151 隻寶可夢，進個人圖鑑 |
| 登入 | 沿用「代碼即密碼」無登入模式（`acjenglish/{代碼}`） |

資料形狀刻意與加分網站一致（`students[] / prizes[]`），讓扭蛋與圖鑑模組可直接共用：

```
acjenglish/{代碼} = {
  students: [ { name, avatar, score, collection:[{type,name,img,time}],
                levels:{animal,color,number}, streak:{...},
                srs:{ "animal:cat":{c:連續答對次數, due:下次到期時間} } } ],
  prizes: []
}
```

## 二、給 6 歲的三個取捨（已寫進程式）

1. **答錯扣 0.5 分（v1.3 改）**——原本答錯不扣分，實際用下來她會亂點快速刷分；改成答錯扣 0.5、答對加 1，仍然可以重試、扣到 0 就不再往下扣。罰則刻意只有獎勵的一半。
2. **不需認字讀題**——題目靠圖 + 語音，作答用點選。
3. **一關 5 題**——回饋要短，一關結束立刻看到分數變化。

## 三、難度設計

### 四個獨立軸

- **軸 1 輔助量**（最重要）：圖+音+字 → 圖+音 → 只有音 → 只有字
- **軸 2 選項數／干擾項**：2 選 1 → 3 選 1 → 4 選 1；干擾項由「差很多」變成「很像」（cat/cap、red/pink）
- **軸 3 作答方式**：點選 → 連連看 → 拖曳分類 → 排字母拼字 → 打字
- **軸 4 題型組合**：單一主題 → 混合主題 → 兩段式（「點出那隻**藍色的**鳥」）

### v1 實作的難度階梯（軸 1＋軸 2）

| 等級 | 題目顯示 | 選項數 |
|---|---|---|
| L1 | 英文字 + 語音 + 中文 | 2 選 1 |
| L2 | 英文字 + 語音 | 3 選 1 |
| L3 | 只有語音（🎧） | 3 選 1 |
| L4 | 只有語音 | 4 選 1 |

### 自動升降級——**不做難度選單**

給六歲看到「簡單／困難」按鈕，她一定選簡單然後卡住。改成系統自動調整：

- 連續答對 **4 題** → 該主題等級 +1（悄悄拿掉一層輔助）
- 連續答錯 **2 題** → 等級 −1（把輔助加回來），**不顯示任何「你退步了」訊息**
- 等級與連對數存 Firestore，跨裝置延續

### 兩個必須守住的原則

- **加分公式與難度脫鉤**：永遠「答對 = 1 分」。難度高不加倍給分，否則她會發現「停在簡單一直刷分抽寶可夢比較快」。想獎勵挑戰改用一次性彩蛋（例：連對 5 題送 1 顆額外扭蛋）。
- **扭蛋不能變稀有**：10 分一抽從頭到尾不變，難度只影響拿到 10 分的節奏。

## 四、題庫格式

每題只描述「內容」，難度由前端依當下等級即時算出，所以**加題不用改程式**：

```js
{ word:"cat", zh:"貓", img:"🐱", level:1, nearMiss:["cap","cow"] }
```

- `level`：這題最早在第幾級出現
- `nearMiss`：發音相近的字，保留給未來的拼字／聽辨題型
- 圖像一律用 **emoji**（動物）、**色塊**（顏色）、**重複 emoji 數量**（數字）——零版權風險、零載入時間

## 五、類別擴充藍圖

**第一批（已做）**：動物、顏色、數字，各 **30 字**，**起跳 L1**。

**第二批（已做）**：食物 food／身體 body／人物 family／交通 transport／形狀 shape／學校 school／天氣 weather，各 **30 字**，**起跳 L2——一進去就沒有中文提示、3 選 1**。
解鎖條件：第一批三關**都達到 L3**（`UNLOCK_LEVEL`）。解鎖時放一次 🎓 晉級動畫。

**第一批不上鎖**——晉級後仍可隨時回去玩。六歲遇到全新主題連續受挫時，需要一個熟悉的關卡回去刷回信心；把舒適區收走容易讓她整個放棄。

**第三批——要動程式**
- 動作 verbs：需要**動圖或短影片**，靜態圖表達不了
- 情緒 feelings：表情圖可行
- 方位 position（in/on/under/behind）：**已不是單字題**，需同圖多問法的新題型

**注意**：關卡地圖一次只亮 3–4 類。六歲看到十幾個圖示會每個點兩題就跑掉，哪類都學不會。某類達到 L3 才解鎖下一類，讓「解鎖新地圖」本身變成獎勵，與扭蛋互不衝突。

### 2026-08-24：v1.3 SRS 間隔重複、每關 30 字卡、語速 0.85、答錯扣 0.5 分
- **需求**：把 Anki 的 SRS 邏輯帶進答題，但**不要那四顆難易度按鈕**，改由「是否連續 2 次以上答對同一題」自行判斷這題還要不要再出現；每個關卡的字卡補到 30 個；語速 0.85；答錯扣 0.5 分。
- **作法**
  1. **SRS**：每張字卡在 `me.srs["關卡:單字"]` 存 `{ c: 連續答對次數, due: 下次該出現的時間 }`。間隔表 `GAP = [1分, 10分, 1天, 3天, 7天, 15天, 30天]`，答對 `c+1`、答錯 `c` 歸零並排到 1 分鐘後回鍋。**連續答對 2 次（c≥2）這張卡就跳到隔天以後**，等於自動退出這一輪。
     - 出題順序 `pickCards()`：**到期的卡 → 沒看過的新卡 → 都不到期時挑最快到期的**，一關仍固定 5 題。
     - **先錯後對不算連續答對**（`quiz.miss` 旗標），否則她可以用「亂點一次再點對的」把卡片推遠。
     - 難易度完全從答題結果推出來——六歲不會也不該自評「簡單／普通／困難」，這是刻意不放那四顆按鈕的理由。
  2. **每關 30 字卡**（10 關共 300 字），各級距約 L2:11／L3:11／L4:8，確保升到高等級後仍有足夠題目可抽。
  3. **語速 0.85**（`speak()` 預設值與所有呼叫點一致）。
  4. **答錯扣 0.5 分**，`Math.max(0, ...)` 保護不會變負數；分數改用 `fmt()` 顯示（整數不秀 `.0`）。
  5. 地圖卡片加「複習 N 張」，讓她看得到今天還有多少張到期。
  6. 數字關擴到 1000，`faceHTML()` 加上 `COUNT_MAX_EMOJI = 12`——超過 12 就不排 emoji，直接顯示阿拉伯數字（30 顆蘋果六歲數不完）。
- **實測**：以 node 抽出 SRS 函式做離線驗證——新卡 5 張出完 → 各答對一次（c=1，10 分鐘後才到期）→ 強制到期再答對一次（c=2）→ `due` 落在 24 小時後、`dueCount` 由 6 降到 1；答錯後 `c` 歸零、1 分鐘後回鍋。題庫以 node 檢查每關 30 字且無重複單字。

### 2026-08-25：v1.4 顏色關寫出單字、修掉「同一張圖出現兩次」的無解題
- **實測回報**
  1. 顏色關只有色塊，看不出來那個顏色叫什麼——薄荷綠／奶油色／米色這種更是分不出來。
  2. 「家人」關的圖卡模糊不清、無法判斷哪個才對。
- **原因**：第 2 點不是圖太小，是**同一個關卡裡有兩張一模一樣的 emoji**——選項是從同關卡抽的，抽到同圖的兩個字就變成**無解題**。用 node 掃過全部題庫，六個關卡中鏢：
  `family` 👩(mom/woman)、👧(sister/girl/daughter)、👦(brother/boy)、🧒(friend/son)；
  `body` 🦶(foot/toe)、💪(arm/elbow)、🦵(leg/knee)、🧠(head/brain)；
  `school` 🖊️(pen/marker)、🎒(bag/backpack)、🏫(class/school)；
  `weather` 🌧️(rainy/rain)、☁️(cloudy/cloud)；`food` 🍌；`shape` 📐。
- **修正措施**
  1. **顏色關的選項一律把英文單字寫在色塊下面**（`showOptWord`，新增 `.cw` 樣式）。副作用要知道：L1／L2 題目本來就秀單字，於是變成「找一樣的字」；L3／L4 只有語音，才是真正的「聽音→選字＋認色」。
  2. **「家人」改名「人物」**（`id` 仍是 `family`，存檔不受影響）並整關重做：拿掉 man／woman／son／daughter／uncle／aunt／cousin 這些**在 emoji 上必然撞圖**的字，換成圖像明確可辨的角色與職業（king／queen／police／worker／guard／cook／farmer／singer／pilot／dancer／astronaut／scientist／artist／judge／clown／ninja／superhero…）。
  3. 其餘撞圖逐一換字或換圖：toe→👣、knee→palm 🤚、elbow→lungs 🫁、brain→nail 💅、corner→cylinder 🥫、class→dictionary 📕、backpack→bell 🔔、marker→calendar 📅、cloudy→⛅、rain→💧、banana milk→lemon 🍋。
  4. 加了一條檢查：**同一關卡內 `img` 不得重複**，加題時務必先跑過（見下方指令）。
- **驗證**：node 掃描十關 —— 每關 30 字、單字無重複、**圖片皆不重複**。
