# ACJ 皙潔英文闖關 — 設計與決策紀錄

日期：2026-08-24　對象：林皙潔（6 歲）

## 一、定位與架構決策

| 項目 | 決定 |
|---|---|
| 站別 | **獨立新站**，不掛在加分網站底下 |
| Firebase | 共用既有專案 `classroom-gacha-rewards`，但用**獨立集合 `acjenglish`**（比照喵喵版 `kitty` 的做法），與 `classes` / `kitty` 互不干擾 |
| 技術 | 純前端單檔 `index.html` + `questions.js` + `pokemon-data.js`，無建置流程 |
| 發音 | 瀏覽器內建 **Web Speech API**（`speechSynthesis`, `en-US`, rate 0.85），不需任何音檔 |
| 獎勵 | 沿用既有扭蛋規則：**滿 10 分可扭，扭一次扣 10 分**，抽第一世代 151 隻寶可夢，進個人圖鑑 |
| 登入 | 沿用「代碼即密碼」無登入模式（`acjenglish/{代碼}`） |

資料形狀刻意與加分網站一致（`students[] / prizes[]`），讓扭蛋與圖鑑模組可直接共用：

```
acjenglish/{代碼} = {
  students: [ { name, avatar, score, collection:[{type,name,img,time}],
                levels:{animal,color,number}, streak:{...} } ],
  prizes: []
}
```

## 二、給 6 歲的三個取捨（已寫進程式）

1. **答錯不扣分**——只給溫和提示、可重試。六歲被扣分會直接放棄。
2. **不需認字讀題**——題目靠圖 + 語音，作答用點選。
3. **一關 5 題**——回饋要短，一關結束立刻看到分數變化。

## 三、難度設計

### 四個獨立軸

- **軸 1 輔助量**（最重要）：圖+音+字 → 圖+音 → 只有音 → 只有字
- **軸 2 選項數／干擾項**：2 選 1 → 3 選 1 → 4 選 1；干擾項由「差很多」變成「很像」（cat/cap、red/pink）
- **軸 3 作答方式**：點選 → 連連看 → 拖曳分類 → 排字母拼字 → 打字
- **軸 4 題型組合**：單一主題 → 混合主題 → 兩段式（「點出那隻**藍色的**鳥」）

### v1 實作的難度階梯（軸 1＋軸 2）

| 等級 | 題目顯示 | 選項數 |
|---|---|---|
| L1 | 英文字 + 語音 + 中文 | 2 選 1 |
| L2 | 英文字 + 語音 | 3 選 1 |
| L3 | 只有語音（🎧） | 3 選 1 |
| L4 | 只有語音 | 4 選 1 |

### 自動升降級——**不做難度選單**

給六歲看到「簡單／困難」按鈕，她一定選簡單然後卡住。改成系統自動調整：

- 連續答對 **4 題** → 該主題等級 +1（悄悄拿掉一層輔助）
- 連續答錯 **2 題** → 等級 −1（把輔助加回來），**不顯示任何「你退步了」訊息**
- 等級與連對數存 Firestore，跨裝置延續

### 兩個必須守住的原則

- **加分公式與難度脫鉤**：永遠「答對 = 1 分」。難度高不加倍給分，否則她會發現「停在簡單一直刷分抽寶可夢比較快」。想獎勵挑戰改用一次性彩蛋（例：連對 5 題送 1 顆額外扭蛋）。
- **扭蛋不能變稀有**：10 分一抽從頭到尾不變，難度只影響拿到 10 分的節奏。

## 四、題庫格式

每題只描述「內容」，難度由前端依當下等級即時算出，所以**加題不用改程式**：

```js
{ word:"cat", zh:"貓", img:"🐱", level:1, nearMiss:["cap","cow"] }
```

- `level`：這題最早在第幾級出現
- `nearMiss`：發音相近的字，保留給未來的拼字／聽辨題型
- 圖像一律用 **emoji**（動物）、**色塊**（顏色）、**重複 emoji 數量**（數字）——零版權風險、零載入時間

## 五、類別擴充藍圖

**v1（已做）**：動物、顏色、數字，各 10 字。

**第二批——零開發成本，只加 JSON**
食物 food／身體 body／家庭 family／交通 transport／形狀 shape／文具學校 school／天氣 weather

**第三批——要動程式**
- 動作 verbs：需要**動圖或短影片**，靜態圖表達不了
- 情緒 feelings：表情圖可行
- 方位 position（in/on/under/behind）：**已不是單字題**，需同圖多問法的新題型

**注意**：關卡地圖一次只亮 3–4 類。六歲看到十幾個圖示會每個點兩題就跑掉，哪類都學不會。某類達到 L3 才解鎖下一類，讓「解鎖新地圖」本身變成獎勵，與扭蛋互不衝突。

## 六、參考案例

- [EnglishForge](https://englishforge.vercel.app/)——多題型 + XP + 徽章的純網頁英文闖關，最接近本專案
- [Starfall](https://www.starfall.com/)、[British Council LearnEnglish Kids](https://learnenglishkids.britishcouncil.org/)——學齡前題型典範：全語音指令、點圖作答、不打字
- Moodle「Level Up!」外掛、Habitica——XP／等級曲線做法可參考，但對六歲太複雜，本專案刻意只留「分數」單一貨幣
